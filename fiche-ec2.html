La trame, 1 h 30

Le même ordre à chaque fois. On ne note que pendant les mises en perspective.

  1. Accueil5 min

    Se présenter, Yeita en deux phrases, le cadre de l'heure et demie. Pas de pitch.

  2. Pour démarrer15 min

    Son objectif, son contexte, les décisions clés récentes. Sert à choisir le premier use case.

  3. Mises en perspective50 min

    Les quatre use cases, un par diamant. Douze notes, une toutes les quatre minutes.

  4. Aspirations15 min

    Formations en tête, autonomie ou accompagnement, freins à rejoindre Yeita. Non noté.

On note l'étape, pas le critère

Les critères rangés sous chaque étape servent à placer la note. Ils resservent au bilan annuel. Pas de note sans fait rapporté.

Junior, 0 à 1 : connaît, a vu faire, a été accompagné.Intermédiaire, 2 à 3 : a fait, commence à décider seul.Senior, 3 à 4 : décide, adapte, fait monter les autres.

La lecture

Profil notéAttendu Yeita au palierAnneaux : 1 à 4

    Douze axes, quatre quartiers

    Le quartier dit le diamant, le rayon dit l'étape. Le pointillé est l'attendu sur le palier discuté : une référence de discussion, pas un seuil d'admission.

    Code EC2, pour la carte d'identité

    —

    Le code porte les douze notes, le palier et le rôle. Les critères, les exemples cités et les aspirations restent dans le compte rendu Notion.

    L'attendu Yeita, palier par palier

    L'attendu se répartit étape par étape. Le plancher est à 1 et jamais à 0 : un 0 veut dire « pas vu », pas « pas attendu ». Ces quarante-huit valeurs sont une hypothèse de travail, à arbitrer avec la grille de salaire 2026.

    Ce qui passe à l'EC3 s'écrit au débrief, dans la fiche de passation candidat, volet EC2 → EC3.
