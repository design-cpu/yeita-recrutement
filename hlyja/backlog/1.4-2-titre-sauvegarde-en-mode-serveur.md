# En mode serveur, renommer la section « Sauvegarde et exemples »

## Résumé
Sur le tableau des candidatures, la section repliée s'appelle « Sauvegarde et exemples » dans les deux modes. En mode serveur, depuis la 1.4, on n'y charge plus d'exemples (seul « Retirer les exemples » apparaît, et seulement si la base en contient), et l'export n'est plus une sauvegarde : la section dit elle-même « Un export est une copie : supprime-la après usage. » Un titre propre au mode serveur éviterait ce message contradictoire.

## Priorité
**Basse** — titre trompeur mais sans effet sur les données, le texte de la section dit déjà ce qu'est l'export ; à traiter avec 1.4-1 dans une même version express.

## Détail
### Proposition
En mode serveur, remplacer le titre `tableau.sauvegarde.titre` de `candidatures/index.html` l. 78 par un texte propre (ex. « Export et import », ou « Export, import et exemples » quand « Retirer les exemples » est visible ; texte à valider par l'utilisateur), clé `tableau.sauvegarde.titreServeur` dans `assets/wording.fr.js`. Mode navigateur inchangé.
### Bénéfice
Pour les recruteurs en mode serveur : un titre qui ne promet ni une sauvegarde (la base est sur le serveur ; l'export est une copie à supprimer) ni des exemples qu'on ne peut plus charger.
### Existant à réutiliser
La bascule faite en 1.4 pour le tableau vide dans `DEMARRAGE.pret.then` de `candidatures/index.html` (l. 322-327 : `data-t` changé vers `tableau.vide.texteServeur`), sur `DEMARRAGE.mode()` ; le texte `serveur.exportTexte` déjà choisi selon le mode (l. 218).
### Effort
S : une clé de texte, une bascule de `data-t`, un contrôle dans `tools/e2e-serveur.py` (et un dans `tools/e2e-candidatures.py` pour le mode navigateur).
