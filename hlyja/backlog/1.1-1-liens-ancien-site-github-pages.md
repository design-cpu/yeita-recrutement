# Le guide présente encore le site du recrutement comme « GitHub Pages »

> Titre d'origine (1.1) : « Les liens vers l'ancien site GitHub Pages mènent à une page 404 ». Les liens sont corrigés en v1.3 ; reste le libellé.

## Résumé
Depuis la v1.3, le lien « Ouvrir sur le site » et la ligne « Site du recrutement » de l'inventaire du guide mènent bien à `recrutement.yeita.fr` (ils renvoyaient avant vers l'ancien site GitHub Pages, en 404). Il reste un libellé : l'inventaire présente toujours ce site comme « GitHub Pages », ce qui est faux depuis la v1.1. Un lecteur du guide peut croire que le site est encore publié sur GitHub.

## Priorité
**Basse** — depuis la v1.3, les deux liens mènent à `recrutement.yeita.fr` ; il ne reste qu'un libellé faux (« GitHub Pages ») dans l'inventaire du guide (constaté, `index.html` l. 431).

(1.1 : moyenne, lien mort reproduit.)

## Détail
### Reproduire
1. Ouvrir une page imprimable (ex. la carte d'identité) dans l'artefact Claude : le bouton d'impression est masqué, la note propose « Ouvrir sur le site ».
2. Cliquer le lien, ou la ligne « Site du recrutement » de l'inventaire de `index.html`.
### Attendu
Le lien ouvre la même page sur `https://recrutement.yeita.fr/` (connexion Google pour les pages protégées).
### Observé
`https://leofuster-story.github.io/yeita-recrutement/…` → 404.
### Où
- `assets/yeita.js` l. 169-172 : commentaires « GitHub Pages » et `var SITE = "https://leofuster-story.github.io/yeita-recrutement/";` (utilisé l. 185 et exporté l. 216).
- `index.html` l. 431 : `site: {name:"Site du recrutement", sub:"GitHub Pages", …, href:YEITA.SITE, …}`.
Piste : `SITE = "https://recrutement.yeita.fr/"`, `sub:"recrutement.yeita.fr"`, commentaires mis à jour ; relancer `tools/e2e-liens.py`.
### Preuve
`curl -s -o /dev/null -w '%{http_code}' https://leofuster-story.github.io/yeita-recrutement/` → `404` (idem pour `/candidatures/` et `/assets/data-diamants.js`), le 2026-10-26.

## Traitement en 1.3
- Fait : `assets/yeita.js` l. 173 : `var SITE = "https://recrutement.yeita.fr/";` (spec 1.3, R36), commentaires mis à jour ; « Ouvrir sur le site » et la ligne « Site du recrutement » de l'inventaire (`href:YEITA.SITE`) mènent au bon site.
- **Reste (statut `ouvert`)** : `index.html` l. 431 : `site: {name:"Site du recrutement", sub:"GitHub Pages", …}` : le sous-titre affiché dit encore « GitHub Pages ». Piste : `sub:"recrutement.yeita.fr"`, puis `tools/e2e-liens.py`. Candidat au mode express.
