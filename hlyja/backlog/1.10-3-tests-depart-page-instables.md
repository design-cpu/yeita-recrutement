# Tests « départ de la page » du mode serveur instables

## Résumé
Dans `tools/e2e-serveur.py`, « départ de la page (candidat.html), PUT précédent lent » et « départ de la page (ec1.html) » échouent une fois sur deux à trois dans le conteneur de test, aussi bien sur `main` (avant la 1.10) que sur la branche 1.10. L'envoi `keepalive` au départ de la page n'arrive pas toujours avant la fermeture.

## Priorité
**Moyenne** — un test instable cache les vraies régressions ; en usage réel, la dernière frappe peut se perdre si on quitte la page dans les 400 ms.

## Détail
### Reproduire
`python3 tools/build.py _site && python3 tools/e2e-serveur.py`, trois fois de suite.
### Observé
3 lancements sur `main` (27 octobre 2026) : les deux contrôles en échec au moins une fois ; « PUT : 200 200 200 200 » (le PUT de départ n'apparaît pas).
### Piste
Attendre l'événement réseau du PUT de départ dans le test plutôt qu'une durée fixe, puis vérifier côté pages (`DOSSIER.partir`, `partirPartie`) que l'envoi part bien sur `pagehide` dans tous les cas.
