# La publication embarque CONTRIBUER.md, .gitattributes et .nojekyll

## Résumé
`tools/build.py` copie dans le site publié trois fichiers qui n'y servent à rien : le guide de contribution `CONTRIBUER.md`, `.gitattributes`, et `.nojekyll`, qu'il écrit lui-même pour GitHub Pages alors que GitHub Pages n'est plus utilisé. Ils sont protégés par la connexion Google, donc sans fuite publique, mais l'image n'est pas « rien de trop ».

## Priorité
**Basse** — aucun effet : les trois fichiers sont protégés (302 vers Google) et ne contiennent rien de sensible.

## Détail
### Constat
`tools/build.py` : `SKIP` (l. 8-9) ne liste ni `CONTRIBUER.md` ni `.gitattributes` ; l. 25 : `open(os.path.join(DST, ".nojekyll"), "w").close()`.
### Preuve
QA 1.1, S2 : `ls -A` du site construit → « `.gitattributes .nojekyll CONTRIBUER.md assets candidatures …` ».
### Risque si on ne fait rien
Fichiers inutiles dans `/srv/site` ; un reste de GitHub Pages qui entretient la confusion.
### Piste
Ajouter `CONTRIBUER.md` et `.gitattributes` à `SKIP`, supprimer l'écriture de `.nojekyll`, et dans le même geste retirer `STORAGE.md` de `SKIP` (1.0-2, même ligne). Relancer `node tools/test-store.js` et les tests `tools/e2e-*.py`.
